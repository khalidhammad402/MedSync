Designed as a lightweight add-on that opens from inside existing practice-software dashboards, in the style of a SMART on FHIR launch, so clinics do not have to replace their core IT. This prototype demonstrates the concept with a mock host and FHIR-shaped data. Real integration would go through each vendor's partner interfaces and the applicable gematik specifications.

Examples of market-leading systems such as CGM, medatixx or TURBOMED illustrate the kind of host system this would sit beside. Illustrative only, not affiliated, no integration exists.

What is simulated here

  • Contract data
  • Dispensing feed
  • Shortage feed
  • Appearance data
  • Conversation input (typed, no microphone)
